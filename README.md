## 📖 About

A simple and elegant password generator that creates strong, secure passwords with customizable options. Built as a portfolio project to demonstrate Vue 3 Composition API, TypeScript, and static site generation

---

## ✨ Features

- 🔑 **Customizable length** — from 4 to 20 characters
- 🎯 **Character options** — uppercase, lowercase, numbers, symbols
- 📊 **Strength indicator** — visual feedback with color-coded bar
- 📋 **One-click copy** — copy password to clipboard
- ⚡ **Real-time updates** — password regenerates on option change
- 🎨 **Clean UI** — minimalistic, responsive, and mobile-friendly
- 🚀 **SSG** — static site generation for fast loading
